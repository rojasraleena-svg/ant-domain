## 2. MVP 核心策略：单点突破

MVP 不追求全量覆盖，而是选取一个高价值、高代表性的子集做深做透：

| 模块 | PRD 原范围 | MVP 实际范围 | 缩窄原因 |
|------|-----------|-------------|---------|
| **资料库** | 全亚科 / 全属 / 全种 | **仅蚁亚科（Formicinae）** | 蚁亚科是国内最常见、饲养群体最大的亚科，新手入门首选 |
| **生活史** | 通用生活史 + 多物种差异化 | **以弓背蚁属（Camponotus）为标杆物种** | 弓背蚁是国内饲养量最大、资料最丰富的属，代表性极强 |
| **我的蚁群** | 支持全物种记录 | **优先支持弓背蚁属，预留扩展接口** | 与生活史内容对齐，降低首版复杂度 |

## 3. 资料库 MVP：蚁亚科（Formicinae）

### 3.1 为什么选蚁亚科

* 国内养蚁用户中，蚁亚科占比最高（估计 60%+）
* 包含弓背蚁、拟黑多刺蚁、日本弓背蚁等热门物种
* 饲养难度跨度大（从新手友好到进阶），适合验证分层体验
* 分类体系清晰，资料来源相对可靠

### 3.2 覆盖范围

#### 3.2.1 亚科信息页

* 蚁亚科概述（形态特征、分布、代表属）
* 与其他亚科的区分要点
* 总体饲养特点

#### 3.2.2 属级覆盖（MVP 至少包含以下属）

| 序号 | 属名（中文） | 学名 | 优先级 | 理由 |
|------|------------|------|--------|------|
| 1 | **弓背蚁属** | *Camponotus* | P0 | MVP 标杆，必做 |
| 2 | 多刺蚁属 | *Polyrhachis* | P0 | 国内热门，新手友好 |
| 3 | 蚁属 | *Formica* | P1 | 经典属种，资料丰富 |
| 4 | 立毛蚁属 | *Paratrechina* | P1 | 小型蚂蚁代表 |
| 5 | 光胸臭蚁属 | *Oecophylla* | P2 | 特色物种，科普价值高 |
| 6 | 细长蚁属 | *Leptomyrmex* | P2 | 补充多样性 |

> **P0 = MVP 必做，P1 = 尽量做，P2 = 有余力再做**

相比 PRD 原始模板，MVP 版聚焦核心字段：

```

├── 基本信息

│   ├── 学名
│   ├── 分类层级（亚科 → 属 → 种）

│   ├── 推荐温度（°C）
│   ├── 推荐湿度（%）
│   ├── 食性（杂食/肉食/甜食）

├── 婚飞信息
│   ├── 婚飞季节
│   └── 婚飞时间（通常傍晚/雨后等）
```

## 4. 生活史 MVP：弓背蚁属（Camponotus）

### 4.1 为什么选弓背蚁属作为生活史标杆

* 发育周期典型，阶段分明，便于教学
* 饲养人群基数大，用户共鸣强
* 不同弓背蚁种之间生活史差异可控，一套框架可复用
* 冬眠需求明确，可展示完整的季节变化维度

### 4.2 生活史阶段定义（弓背蚁专属）

#### 4.2.1 完整生命周期时间轴

```
婚飞 → 建巢/脱翅 → 卵期 → 幼虫期 → 蛹期
→ 第一批工蚁羽化 → 初期育幼 → 初级扩群
→ 稳定增长 → 成熟群体 → 季节变化/冬眠
```

#### 4.2.2 各阶段详细定义

##### 阶段一：婚飞（Nuptial Flight）

| 项目 | 内容 |
|------|------|
| **定义** | 有翅雄蚁和雌蚁（未来蚁后）在特定天气条件下集体飞行交配 |
| **时间** | 通常 5-8 月，雨后闷热傍晚 |
| **外显特征** | 大量有翅蚂蚁从巢中飞出，空中交配后雄蚁死亡，雌蚁落地脱翅 |
| **持续时间** | 数小时（婚飞本身）；落地后数小时内脱翅 |
| **养殖相关** | 这是获得新蚁后的主要途径；野外采集需注意安全 |
| **常见误区** | "所有蚂蚁同时婚飞" — 实际不同种有不同婚飞窗口 |

##### 阶段二：建巢 / 创群（Colony Founding）

| 项目 | 内容 |
|------|------|
| **定义** | 新生蚁后寻找合适位置，封闭自己开始产卵 |
| **时间** | 婚飞后立即开始，持续 4-8 周（至第一批工蚁出现） |
| **外显特征** | 蚁后体型明显缩小（消耗自身营养）；可见白色卵粒 |
| **常见行为** | 几乎不活动、自我封闭、清理卵周围环境 |
| **注意事项** | **绝对黑暗**、**绝对安静**、**不要打扰**、**不要喂食** |
| **持续时间（弓背蚁）** | 约 4-6 周（因温度而异） |
| **常见误区** | "新蚁后需要喂食" — 错误！初期完全靠自身储备营养 |

##### 阶段三：卵期（Egg Stage）

| 项目 | 内容 |
|------|------|
| **定义** | 蚁后产下的卵，呈米白色椭圆形 |
| **大小** | 约 1mm |
| **外观** | 半透明、微黄白色、光滑 |
| **持续时间（弓背蚁）** | 10-14 天（25°C 条件下） |
| **注意事项** | 不要移动试管/巢穴；保持温湿度稳定 |
| **常见误区** | "卵不动就是死了" — 正常现象，卵不会动 |

##### 阶段四：幼虫期（Larval Stage）

| 项目 | 内容 |
|------|------|
| **定义** | 卵孵化后形成的蠕虫状幼虫，需要被喂养 |
| **外观** | 白色、蠕虫状、不分节或轻微分节、会蠕动 |
| **行为特征** | 被工蚁（或初期由蚁后自身）搬运和喂养 |
| **持续时间（弓背蚁）** | 14-21 天（25°C） |
| **注意事项** | 此阶段开始需要蛋白质食物（但初期仍靠蚁后唾腺分泌） |
| **关键点** | **这是判断蚁群是否健康的重要指标** — 幼虫饱满=健康 |

##### 阶段五：蛹期（Pupal Stage）

| 项目 | 内容 |
|------|------|
| **定义** | 幼虫吐丝结茧（弓背蚁有茧）或不结茧进入预蛹/蛹状态 |
| **外观** | 白色/浅黄色、静止不动、茧壳包裹（弓背蚁有茧） |
| **持续时间（弓背蚁）** | 14-21 天（25°C） |
| **注意事项** | 蛹非常脆弱，避免震动；此阶段对湿度敏感 |
| **常见误区** | "蛹变黑了是正常变色" — 变黑通常意味着死亡或真菌感染 |

##### 阶段六：第一批工蚁羽化（First Workers Eclose）

| 项目 | 内容 |
|------|------|
| **定义** | 第一批蛹羽化为工蚁，标志蚁群从"单后"进入"社会性群体" |
| **时间节点** | 建巢后约 4-6 周（弓背蚁，25°C） |
| **外显特征** | 可见小型浅色工蚁在巢中活动 |
| **意义** | **里程碑事件！** 蚁后不再独自承担所有工作 |
| **行为变化** | 工蚁开始觅食、照顾后续幼虫、清理巢穴 |
| **注意事项** | 此时可以开始少量喂食（糖水为主） |
| **首次喂食建议** | 1:10 糖水，用棉签或小管提供 |

##### 阶段七：初级扩群（Early Growth）

| 项目 | 内容 |
|------|------|
| **定义** | 第一批工蚁工作后，蚁后专注产卵，群体数量逐步增加 |
| **时间范围** | 首批工蚁出现后 1-3 个月 |
| **工蚁数量目标** | 10-50 只（弓背蚁） |
| **关键事件** | 可能经历第一次搬巢（试管空间不足时） |
| **喂食频率** | 每 2-3 天一次 |
| **食物种类** | 糖水 + 少量蛋白质（昆虫尸体） |
| **注意事项** | 控制喂食量，避免污染；观察工蚁活跃度 |

##### 阶段八：稳定增长（Steady Growth）

| 项目 | 内容 |
|------|------|
| **定义** | 群体进入指数增长期，分工明确，各司其职 |
| **时间范围** | 建群 3-12 个月 |
| **工蚁数量** | 50-200+ 只 |
| **群体结构** | 出现明显的工蚁形态分化（大型工蚁/中型/小型） |
| **巢穴需求** | 可能需要搬入正式蚁巢（石膏/亚克力/3D打印） |
| **喂食** | 定期投喂，多样化食谱 |
| **风险点** | 群体增大后疾病传播更快；注意卫生管理 |

##### 阶段九：成熟群体（Mature Colony）

| 项目 | 内容 |
|------|------|
| **定义** | 群体达到较大规模，产生繁殖蚁（雄蚁+新雌蚁） |
| **时间范围** | 建群 2 年以上 |
| **规模** | 数百至数千只工蚁 |
| **标志性事件** | 出现有翅繁殖蚁 → 准备下一次婚飞 |
| **管理要点** | 大型群体需要更大巢穴；可能需要分蜂 |
| **特殊说明** | 家养环境下不一定自然产生繁殖蚁 |

##### 阶段十：季节变化 / 冬眠（Seasonal Change / Hibernation）

| 项目 | 内容 |
|------|------|
| **定义** | 温带地区弓背蚁在冬季进入休眠状态 |
| **触发条件** | 温度持续低于 15°C，光照缩短 |
| **表现** | 活动大幅减少、停止产卵、聚集在巢穴深处 |
| **冬眠温度** | 5-10°C（不可低于 0°C 或高于 15°C） |
| **时长** | 约 3-4 个月（11 月 - 次年 2-3 月） |
| **注意事项** | 冬眠前确保群体足够强壮；冬眠期间不喂食；逐渐降温/升温 |
| **不冬眠的后果** | 蚁后过度消耗、寿命缩短、次年繁殖力下降 |
| **热带种例外** | 热带弓背蚁种不需要冬眠 |

## 5. 我的蚁群 MVP：弓背蚁优先

### 5.3 AI 分析 — MVP 能力边界

| 功能 | MVP 实现 | 说明 |
|------|---------|------|
| 日志摘要 | 自动生成 | 用户提交日志后，AI 生成一句话摘要 |
| 阶段判断 | 基于规则 + AI 辅助 | 结合日志内容 + 时间线推断当前所处阶段 |
| 成长周报 | 每周汇总 | 汇总本周日志，生成简要回顾 |
| 风险提示 | 规则引擎 | 检测异常关键词（死亡、不发卵、停止进食等）并提醒 |
| 下一步建议 | 模板化 + AI | 基于当前阶段推送对应生活史内容的操作建议 |

### 5.4 成长时间线 — MVP 事件类型

系统自动识别并在时间线上标记的事件：

| 事件类型 | 触发条件 | 展示样式 |
|---------|---------|---------|
| 建档 | 创建蚁群时 | 起点 |

| 结束冬眠 | 阶段从"冬眠"变更 | 里程碑 |
| 异常事件 | 日志选中"异常情况" | 警告样式 |
| 手动标记 | 用户手动添加 | 自定义 |

## 6. 模块联动 — MVP 版

### 6.1 资料库 → 生活史（弓背蚁闭环）

```
用户浏览 日本弓背蚁 物种详情页
    ↓
页面底部："查看弓背蚁完整生活史 →"
    ↓
跳转至 弓背蚁属生活史总览页（含 10 阶段时间轴）
    ↓
点击任意阶段 → 阶段详情页
```

## 7. 数据结构 — MVP 版（基于 PRD 精简）

### 7.1 物种表 `species`

```sql
CREATE TABLE species (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    name_cn         TEXT NOT NULL,           -- 中文名
    name_lat        TEXT NOT NULL UNIQUE,    -- 学名
    subfamily       TEXT NOT NULL,           -- 亚科（MVP 固定 'Formicinae'）
    genus           TEXT NOT NULL,           -- 属
    subfamily_cn    TEXT,                    -- 亚科中文名
    genus_cn        TEXT,                    -- 属中文名
    summary         TEXT,                    -- 简介
    description     TEXT,                    -- 详细描述（富文本/Markdown）
    worker_size     TEXT,                    -- 工蚁体长（如 "6-12mm"）
    queen_size      TEXT,                    -- 蚁后体长
    body_color      TEXT,                    -- 体色
    key_features    TEXT,                    -- 关键识别特征
    difficulty      INTEGER DEFAULT 1,       -- 饲养难度 1-3（低/中/高）
    beginner_friendly BOOLEAN DEFAULT FALSE, -- 是否适合新手
    temp_min        INTEGER,                 -- 最低温度 °C
    temp_max        INTEGER,                 -- 最高温度 °C
    temp_optimal    TEXT,                    -- 最适温度（如 "24-28"）
    humidity_min    INTEGER,                -- 最低湿度 %
    humidity_max    INTEGER,                -- 最高湿度 %
    humidity_optimal TEXT,                  -- 最适湿度
    diet_type       TEXT,                   -- 食性（omnivore/carnivore etc.）
    nest_type       TEXT,                   -- 巢型建议
    need_hibernation BOOLEAN DEFAULT FALSE, -- 是否需要冬眠
    distribution    TEXT,                   -- 分布区域
    habitat         TEXT,                   -- 生活环境
    flight_season   TEXT,                   -- 婚飞季节
    flight_time     TEXT,                   -- 婚飞时间
    colony_scale    TEXT,                   -- 群体规模特点
    behavior_notes  TEXT,                   -- 行为特点
    faq             TEXT,                   -- 常见问题（JSON array）
    life_stage_overview TEXT,              -- 生活史阶段概览
    similar_species TEXT,                  -- 相似物种 ID 列表（JSON array）
    reference       TEXT,                   -- 参考资料
    tags            TEXT,                   -- 标签（JSON array）
    cover_image     TEXT,                   -- 封面图 URL
    status          INTEGER DEFAULT 1,      -- 状态 1=启用 0=禁用
    sort_order      INTEGER DEFAULT 0,      -- 排序
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 7.2 生活史阶段表 `life_stages`

```sql
CREATE TABLE life_stages (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    stage_key       TEXT NOT NULL UNIQUE,   -- 阶段标识（如 nuptial_flight）
    name            TEXT NOT NULL,          -- 阶段名称
    name_en         TEXT,                   -- 英文名
    order_index     INTEGER NOT NULL,       -- 时间轴排序
    definition      TEXT,                   -- 阶段定义
    external_features TEXT,                 -- 外显特征
    common_behaviors TEXT,                  -- 常见行为
    care_notes      TEXT,                   -- 养殖注意事项
    common_mistakes TEXT,                  -- 常见误区
    duration_base   TEXT,                   -- 基准持续时间
    duration_note   TEXT,                   -- 持续时间说明（物种差异）
    prev_stage      TEXT,                   -- 前一阶段 stage_key
    next_stage      TEXT,                   -- 后一阶段 stage_key
    milestone       BOOLEAN DEFAULT FALSE,  -- 是否为里程碑阶段
    icon            TEXT,                   -- 阶段图标
    color           TEXT,                   -- 主题色
    target_genus    TEXT DEFAULT 'Camponotus', -- 目标属（MVP 固定弓背蚁）
    tips            TEXT,                   -- 小贴士（JSON array）
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 7.3 蚁群表 `colonies`

```sql
CREATE TABLE colonies (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id         INTEGER NOT NULL,       -- 用户 ID
    name            TEXT NOT NULL,          -- 蚁群名称
    species_id      INTEGER NOT NULL,       -- 关联 species.id
    avatar          TEXT,                   -- 封面图
    founded_date    DATE NOT NULL,          -- 建档日期
    acquired_date   DATE,                   -- 获得日期
    acquire_method  TEXT,                   -- 获得方式
    queen_count     INTEGER DEFAULT 1,      -- 蚁后数量
    current_stage   TEXT,                   -- 当前生活史阶段（关联 life_stages.stage_key）
    worker_range    TEXT,                   -- 工蚁数量区间
    notes           TEXT,                   -- 备注备注
    status          INTEGER DEFAULT 1,      -- 状态 1=正常 2=冬眠 3=已结束
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (species_id) REFERENCES species(id)
);
```

### 7.4 日志表 `colony_logs`

```sql
CREATE TABLE colony_logs (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    colony_id       INTEGER NOT NULL,       -- 关联 colonies.id
    user_id         INTEGER NOT NULL,       -- 用户 ID
    date            DATE NOT NULL,          -- 记录日期
    title           TEXT NOT NULL,          -- 日志标题
    content         TEXT,                   -- 日志正文
    stage           TEXT,                   -- 当时所处阶段
    worker_count    TEXT,                   -- 工蚁数量区间
    egg_status      TEXT,                   -- 卵状态
    larva_status    TEXT,                  -- 幼虫状态
    pupa_status     TEXT,                   -- 蛹状态
    feeding_record  TEXT,                   -- 喂食记录
    temperature     REAL,                   -- 温度 °C
    humidity        REAL,                   -- 湿度 %
    abnormal_type   TEXT,                   -- 异常类型
    abnormal_detail TEXT,                   -- 异常详情
    images          TEXT,                   -- 图片 URL 列表（JSON array）
    ai_summary      TEXT,                   -- AI 生成的摘要
    event_type      TEXT,                   -- 事件类型（自动识别）
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (colony_id) REFERENCES colonies(id)
);
```

### 7.5 阶段-物种差异表 `stage_species_diff`（预留扩展）

## 9. 技术约束与决策

### 9.1 技术栈建议（待确认）

| 层面 | 建议 | 备注 |
|------|------|------|
| 前端框架 | Next.js / React | SSR 支持 SEO（资料库需要） |
| UI 组件库 | Ant Design Mobile 或自定义 | 移动端优先 |
| 状态管理 | Zustand / Jotai | 轻量即可 |
| 数据库 | SQLite / PostgreSQL | MVP 阶段 SQLite 即可 |
| ORM | Prisma / Drizzle | 类型安全 |
| AI 接口 | Claude API / OpenAI API | 用于摘要生成 |
| 图片存储 | 本地 / OSS | MVP 先本地 |
| 部署 | Vercel / 自建服务器 | 视团队情况 |

### 9.2 SEO 考虑

资料库页面需要被搜索引擎收录，因此：
- 物种详情页必须支持 SSR/SSG
- 需要 meta 标签优化（标题、描述、结构化数据）
- URL 设计需语义化：`/species/camponotus-japonicus`

### 9.3 国际化预留

虽然 MVP 仅中文，但数据结构中保留 `name_en` / `name_lat` 等字段，为将来多语言做准备。
